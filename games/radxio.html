What is radx.io?

  • radx.io the codable math game® is a number coding game system designed to build fluency with patterns, operations, and number base conversions using tangible game pieces.
  • We've developed our featured game, called Ada!, to generate a fast-paced decimal to binary conversion challenge. Speed solving against opponents has you thinking fast and efficiently to be the first to solve the code sequence.
  • To keep it simple, we opted to present one game to get you started, but you can imagine that with just on-off bits, you can develop an almost infinite number of game variants.
  • We've tested the game at family game nights, high school computer science classrooms, and many one-on-one sessions, which all helped tighten and hone gameplay mechanics.

Game specs

  • Players: 1–4
  • Time: 15–20 minutes
  • Age: 10+ (Children under 10 with strong math skills can easily play 4-bit Ada!)
  • Cards + Dice Version: 128 Code Cards, 10 Wildcards, 32 dice (“bits”), 4 Ciphers, 2 Solution Cards
  • Cards Version: 128 Code Cards, 10 Wildcards, 4 Player Decks, 2 Solution Cards

Code Bits Pattern Reference

Learn in layers: 4-bit “nibbles” up to full 8-bit bytes. A dot = "on", blank = "off". The included radx.io "cipher board" game pieces will help you do conversions in real time.
